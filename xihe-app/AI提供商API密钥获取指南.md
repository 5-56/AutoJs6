## 1. Google Gemini（强烈推荐）🌟

### 为什么推荐？
- ✅ **完全免费**
- ✅ 强大的代码生成能力
- ✅ 最新的gemini-2.0-flash-exp模型
- ✅ 响应速度快
- ✅ 免费额度充足

### 获取步骤（3分钟）

#### 步骤1：访问API页面
```
https://makersuite.google.com/app/apikey
```

#### 步骤2：登录Google账号
- 使用你的Gmail账号登录

#### 步骤3：创建API密钥
- 点击 "Create API Key" 按钮
- 选择项目或创建新项目
- 复制生成的API密钥

#### 步骤4：在羲和中配置
```
1. 打开羲和 → 设置 → AI提供商
2. 选择 "Google Gemini [免费]"
3. 粘贴API密钥
4. 点击 "获取模型列表"
5. 选择 "gemini-2.0-flash-exp"
6. 保存配置
```

### API密钥格式示例
```
AIzaSyABCDEFGHIJKLMNOPQRSTUVWXYZ1234567890
```

### 推荐模型
- **gemini-2.0-flash-exp** - 最新最快（推荐）
- **gemini-1.5-flash** - 稳定快速
- **gemini-1.5-pro** - 功能强大
