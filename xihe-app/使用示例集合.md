## 场景1：自动签到

### 使用AI（推荐）

```
你: "帮我自动签到"

羲和执行:
1. 分析屏幕 → 找到"签到"按钮
2. AI生成脚本
3. 执行脚本
4. ✅ 签到成功
```

### 使用脚本模板

```
1. 主界面 → 脚本模板
2. 选择"实用脚本" → "自动签到"
3. 点击执行
4. ✅ 完成
```

### 生成的脚本
```javascript
auto();
sleep(2000);

// 多种方式查找签到按钮
var signBtn = text("签到").findOne(3000);
if (!signBtn) {
    signBtn = textContains("签到").findOne(2000);
}
if (!signBtn) {
    signBtn = desc("签到").findOne(2000);
}

if (signBtn) {
    signBtn.click();
    toast("签到成功");
} else {
    toast("未找到签到按钮");
}
```

## 场景2：自动填写登录表单

### AI对话

```
你: "帮我填写登录表单，用户名是test，密码是123456"

羲和:
1. 分析屏幕 → 找到2个EditText
2. AI生成脚本（包含用户名和密码）
3. 执行脚本
4. ✅ 自动填写并登录
```

### 生成的脚本
```javascript
auto();
sleep(1500);

// 填写用户名
var username = className("EditText").findOne(3000);
if (username) {
    username.setText("test");
    toast("已填写用户名");
    sleep(500);
}

// 填写密码
var inputs = className("EditText").find();
if (inputs.length >= 2) {
    inputs[1].setText("123456");
    toast("已填写密码");
    sleep(500);
}

// 点击登录按钮
var loginBtn = text("登录").findOne(3000);
if (!loginBtn) {
    loginBtn = textContains("登录").findOne(2000);
}

if (loginBtn) {
    loginBtn.click();
    toast("已提交");
} else {
    toast("未找到登录按钮");
}
```

## 场景3：滚动查找内容

### AI对话

```
你: "帮我向下滚动直到找到设置选项"

羲和:
1. AI理解需求
2. 生成循环滚动脚本
3. 执行：不断滚动并查找
4. ✅ 找到后自动停止
```

### 生成的脚本
```javascript
auto();
sleep(1000);

var maxScroll = 10; // 最多滚动10次
var found = false;

for (var i = 0; i < maxScroll; i++) {
    toast("正在查找... " + (i + 1) + "/" + maxScroll);
    
    // 查找"设置"
    var target = textContains("设置").findOne(1000);
    if (target) {
        target.click();
        toast("找到并点击了设置");
        found = true;
        break;
    }
    
    // 向下滑动
    var width = device.width;
    var height = device.height;
    swipe(width / 2, height * 0.7, width / 2, height * 0.3, 500);
    sleep(1000);
}

if (!found) {
    toast("未找到设置选项");
}
```

## 场景4：连续操作流程

### AI对话

```
你: "帮我打开设置，然后点击关于，再返回"

羲和:
1. AI理解多步骤需求
2. 生成包含多个步骤的脚本
3. 按顺序执行
4. ✅ 完成整个流程
```

### 生成的脚本
```javascript
auto();
toast("开始执行流程");
sleep(1500);

// 步骤1: 打开设置
var settingsBtn = text("设置").findOne(5000);
if (settingsBtn) {
    settingsBtn.click();
    toast("已打开设置");
    sleep(2000);
} else {
    toast("未找到设置");
    exit();
}

// 步骤2: 点击关于
var aboutBtn = text("关于").findOne(5000);
if (aboutBtn) {
    aboutBtn.click();
    toast("已打开关于");
    sleep(2000);
} else {
    toast("未找到关于");
}

// 步骤3: 返回
back();
toast("已返回");
sleep(1000);

toast("流程完成");
```

## 场景5：智能等待

### AI对话

```
你: "等待页面加载完成后点击继续"

羲和:
1. AI生成等待逻辑
2. 等待特定元素出现
3. 出现后自动点击
4. ✅ 完成
```

### 生成的脚本
```javascript
auto();
toast("等待页面加载...");

// 等待"继续"按钮出现（最多等待15秒）

    toast("页面已加载");

    continueBtn.click();
    toast("已点击继续");
} else {
    toast("等待超时");
}
```

## 场景6：条件判断

### AI对话

```
你: "如果有确定按钮就点击，没有就点击取消"

羲和:
1. AI理解条件逻辑
2. 生成if-else判断
3. 执行
4. ✅ 根据实际情况操作
```

### 生成的脚本
```javascript
auto();
sleep(1000);

// 先查找确定按钮
var confirmBtn = text("确定").findOne(2000);

if (confirmBtn) {
    confirmBtn.click();
    toast("已点击确定");
} else {
    // 没有确定，查找取消
    var cancelBtn = text("取消").findOne(2000);
    if (cancelBtn) {
        cancelBtn.click();
        toast("已点击取消");
    } else {
        toast("两个按钮都没找到");
    }
}
```

## 🎓 学习AutoJs6 API

### 常用API

#### 元素查找
```javascript
text("文本")              // 精确匹配
textContains("文本")      // 包含匹配
id("id")                 // 通过ID查找
className("类名")         // 通过类名查找
desc("描述")             // 通过描述查找
clickable(true)          // 查找可点击元素
```

#### 操作
```javascript
element.click()          // 点击
element.setText("文本")  // 设置文本
click(x, y)             // 点击坐标
press(x, y, duration)   // 长按
swipe(x1, y1, x2, y2, duration)  // 滑动
```

#### 工具
```javascript
sleep(ms)               // 等待（毫秒）
toast("消息")           // 显示提示
log("日志")             // 打印日志
back()                  // 返回键
home()                  // Home键
```
